# appsmith (Seif's fork) — plain-language README

## What this is
This is Seif's copy (a "fork") of **appsmithorg/appsmith**, an open-source platform for building internal tools such as admin panels, dashboards and simple business apps, mostly by dragging and dropping. It connects to 25+ kinds of databases and to any API (a way for programs to talk to each other).

## Who it's for
Teams who need in-house tools quickly without building everything by hand.
